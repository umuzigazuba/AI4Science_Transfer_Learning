# Cow Labor Classification using a CNN

Classify time series of cow body pulsations using a CNN in order to identify cow labor.

## Project Structure

```
promity_cow_series/
├── configs/                        # Hydra config files
│   ├── analysis/                   # parameters model implementations on new cow series
│   ├── data/                       # parameters dataloader 
│   ├── model/                      # parameters CNN model
│   └── trainer/                    # parameters classifier 
├── data/      
│   ├── detection_exports/          # cow time series (needs to be created first)
│   └── saved_models/               # saved CNN models     
├── examples/                       # example scripts 
│   ├── plots/                      # plots of a model's predicted probabilities of labor for a few long time series of body pulsations 
│   └── results_kfolds.txt          # accuracies of each fold for both random and chronological splits & other global statistics
├── logs/                           # logs generated by tensorboard and Weights & Biases
├── notebooks/                      # notebooks for function testing
├── src/
│   ├── models/                     # CNN model definition
│   ├── data/                       # dataloaders and datasets
│   ├── pytorch_version/            # classification and train scripts using only torch
│   ├── utils/                      # plotting and other helper functions
├── .gitignore      
├── README.md          
├── environment.yaml                # dependencies for a conda environment
└── requirements.txt
```

## Installation

Clone both the data and classifier repositories at the same level:

```bash
git clone https://bb.promity.pl/scm/tale/cow_series_data.git
git clone https://bb.promity.pl/scm/tale/promity_cow_series.git
```

Install dependencies:

```bash
cd promity_cow_series

python -m venv cowenv
source cowenv/bin/activate        # Mac/Linux
cowenv\Scripts\activate           # Windows

pip install -r requirements.txt
```

Download the probability series in the `data/` folder

```bash
python ../cow_series_data/cow_series_data/download_dataset.py
```

## Usage

Train on time series in a random order using k-fold cross validation (k=5):

```bash
python src/classify_cow_births.py trainer.tensorboard_logger_name=k_fold_random trainer.model_checkpoint_dir=./data/saved_models/k_fold_random_splits/ trainer.model_checkpoint_name=random_splits_
```

Train on time series in a chronological order using k-fold cross validation (k=5):

```bash
python src/classify_cow_births.py trainer.tensorboard_logger_name=k_fold_chronological trainer.model_checkpoint_dir=./data/saved_models/k_fold_chronological_splits/ trainer.model_checkpoint_name=chronological_splits_
```

Print the statistics of the models of every fold after training on the time series in random and chronological order:

```bash
python examples/results_kfolds.py
```

Run the best model on a random time series and return the predicted and target label:

```bash
python examples/run_example_model.py
```


Run the best model on a long time series:

```bash
python examples/long_cowseries.py
```

The prediction over time is shown in a plot saved in examples/plots/.
